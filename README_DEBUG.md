# デバッグ方針 / PDF解析検証

## 現在の解析方針
- Google Drive検索は受給者番号 `1219856`、対象年＋前年の候補に限定。
- PDF.jsは入力バッファをコピーして扱い、iOS/Safariで文字レイヤーが空になるケースを検出する。
- PDF.jsの文字項目数・文字数だけで「読めた」と判定しない。帳票種別ごとの必須項目と算術整合性まで検証する。
- 文字レイヤーが不足、または主要項目の構造検証に失敗した場合はOCRへフォールバックする。
- OCRは `PSM 11` と `PSM 6` の結果を統合し、片方でラベル、もう片方で金額が取れるケースに対応する。
- OCRで曖昧な場合は確認待ちとし、推測値を実績として確定しない。
- `furusatoState` が主データ。復旧用ストアの古い空データで主データを上書きしない。
- Service Workerキャッシュは `v16`。新しい解析ロジックが旧キャッシュに残らないよう、更新時に旧キャッシュを削除する。
